# 声速测深裁决台

多波束测深在**声速剖面分层**或**姿态时标错位**时，用平均声速的直线声线会产生系统性条带。
本服务对每个波束用**分层声速剖面做射线积分**（Snell 折射 + 自适应 Simpson 数值积分），
并允许保留多个相互竞争的裁决方案（不同剖面有效时段 × 不同姿态时延），
在同一页面上比较海底点带与相邻条带的交叉差。

- 技术栈：Java 17 / Spring Boot 3.5 / SQLite（xerial sqlite-jdbc）/ 原生 SVG
- 固定 fixture：`src/main/resources/fixtures/fixture.json`，随服务首启自动入库

## 安装与演示

```bash
# 安装（跳过测试打包）
mvn -q -DskipTests package

# 演示：先跑自动化测试，再起服务
mvn -q test && mvn -q spring-boot:run -Dspring-boot.run.arguments=--server.port=5567
```

浏览器访问 <http://127.0.0.1:5567>，页面标题为 **声速测深裁决台**。

页面操作：
- 左侧可裁剪每条剖面的有效时段、设置姿态时延（ms）、数值积分容差（秒）、波束角限制（°）。
- “执行裁决”生成一个方案；“生成 0/+600ms 对照”一次生成两个姿态对齐方案。
- 断面 SVG 展示剖面分层（虚线）、每根折射声线（按层分段）与海底点；
  平面 SVG 展示两条测线的海底点带、失败样本和固定交叉点。
- “导出运行记录 JSON”下载当前方案的全部输入口径与结果，用于离线复核。
- “清空数据库并重导 fixture”删除所有表数据后重新导入固定 fixture（等价于手动清空 SQLite 后重启）。

## 数据口径（fixture）

- 两条测线 `L1`（航向 0°）、`L2`（航向 90°），各 11 个 ping（t = 1000…19000 ms），
  每 ping 5 个波束，安装角（相对垂直向下）`-60,-30,0,30,60°`，共 **110** 个波束样本。
- 往返时间（TWTT）按“剖面 A、零横摇、48 m 平坦海底”正演生成，全程保留 9 位小数。
- 剖面为**三层折射结构（四个深度节点）**，深度严格递增：
  - `SVP-A`：0 m/1480，10 m/1475，25 m/1500，50 m/1510 m·s⁻¹，默认有效 `0–9000 ms`
  - `SVP-B`：0 m/1485，10 m/1480，25 m/1505，50 m/1515 m·s⁻¹，默认有效 `10000–20000 ms`
- 两条剖面之间存在一个**时间空档**：ping `t=9500` 不落在任何剖面时段内。
- 姿态为每条测线各自的锚点序列（roll 分段线性，pitch=0），查询时刻 = `pingT − delayMs`。
- 交叉点固定为 ping `t=8600`（在 SVP-A 时段内）；交叉差取两线跨轨零点相邻波束的
  深度线性插值之差（z_L1 − z_L2）。

裁决得到的关键对照（自动测试中固化断言）：

| 方案 | t=5000 最外侧右舷波束 | 交叉差 (t=8600) |
|---|---|---|
| 姿态延迟 0 ms | 水中角 59.0°，深度 49.49 m，**成功** | **−0.0193 m** |
| 姿态延迟 +600 ms | 水中角 58.4°，需深于 50 m，**未支持** | **−0.0373 m** |

波束更接近垂直时同样的往返时间对应更深海底，因此姿态错位后该样本越过剖面最大深度。

## 物理与裁决规则

1. **分层射线积分**：层内等声速，层界面满足 Snell 定律
   `sin θₖ / cₖ = p`（p 为射线参数）。层内单程时间
   `dt = dz / (c·cosθ)`，采用自适应 Simpson 数值积分；
   海底深度由单程时间（TWTT/2）二分反演，残差必须达到给定容差（默认 `1e-9 s`）。
2. **分界面端点只归一层**：层 k 占据区间 `(zₖ, zₖ₊₁]`。
   射线终点恰好等于分界面深度时，该点只属于先到达的上侧一层，下一层不产生零长度段。
3. **失败不回退平均声速**：需要的单程时间超过“射线到达剖面最大深度的时间”时
   状态为 `SOLVE_FAILED / DEPTH_EXCEEDED`；层内发生全反射为 `TOTAL_REFLECTION`；
   迭代残差达不到容差为 `NO_CONVERGENCE`。失败样本的深度字段保持为 NULL。
4. **剖面时段空档不插值**：ping 不落在任何（方案指定的）剖面有效时段内时
   状态为 `NO_PROFILE`，绝不在两个剖面之间外推/拼接。
5. **越界只报告未支持**：波束（解出的终点）越过剖面最大深度时只报未支持，不裁剪、不假解。
6. **姿态不外推**：平移后的查询时刻落在锚点序列之外时为 `NO_ATTITUDE`。
7. **波束角排除**：水中角（安装角 + 横摇）绝对值超过限制的样本标记 `EXCLUDED_ANGLE`，
   不参与射线求解与交叉差，但保留记录。
8. **有效时段不得重叠**：同一方案的剖面窗口重叠或覆盖空档会被拒绝（HTTP 400）。

每个海底点持久化保留：输入波束样本身份（如 `L1-P02-B4`）、所用剖面、姿态版本
（`ATT-DELAY-<n>ms`）与插值所用的两个姿态锚点身份、安装角/水中角/横摇、
深度与跨轨水平距离、时间残差，以及逐段的射线分层（层号、起止深度、声速、层内角、dt/dx）。

## 重放与复核

```bash
# 自动化测试（物理单元 + Spring 集成，使用独立库 data/svp-test.db，启动前自动删除）
mvn -q test
```

测试覆盖：Snell 定律与逐层时间、**分界面端点只归一层**、**超深失败不回退平均声速**、
全反射、严格递增深度校验、两种姿态延迟在 t=5000 的相反结论、空档不跨剖面插值、
波束角排除、交叉差随时延放大、重叠时段拒绝、以及**清空重导后结果可复现**、运行记录导出。

手动复核步骤：
1. 页面点“清空数据库并重导 fixture”（或删除 `data/svp.db*` 后重启）。
2. 点“生成 0/+600ms 对照”，切换两个方案页签。
3. 核对：t=5000 最外侧样本由成功变为 `SOLVE_FAILED/DEPTH_EXCEEDED`；
   t=9500 全部为 `NO_PROFILE`；交叉差由约 1.9 cm 变为约 3.7 cm。
4. 分别导出两个方案 JSON 留档。

SQLite 库默认位于 `./data/svp.db`，可用环境变量 `SVP_DB` 覆盖：

```bash
SVP_DB=/path/to/case.db mvn -q spring-boot:run -Dspring-boot.run.arguments=--server.port=5567
```

## HTTP 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/state` | 剖面/分层/姿态/样本/已有方案 |
| POST | `/api/runs` | 创建裁决方案（时延、波束角限制、容差、剖面窗口） |
| GET | `/api/runs/{id}` | 方案下全部海底点与交叉差 |
| GET | `/api/runs/{id}/export` | 下载运行记录 JSON |
| PUT | `/api/profiles/{id}/window` | 调整某条剖面的默认有效时段 |
| POST | `/api/admin/reimport` | 清空所有裁决数据并重导固定 fixture |
