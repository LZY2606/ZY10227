# 声速测深裁决台

Java / Spring Boot / SQLite 本地裁决台。系统使用多波束往返时间、发射角、姿态样本和分层声速剖面执行射线积分，并保留多套剖面与姿态对齐方案。

## 数据口径

- 固定数据位于 `src/main/resources/fixtures/`，包含剖面、分层、姿态、Ping 和波束样本。
- 分层深度必须严格递增且首尾相接；分层面折射点只归上方一层，界面不重复归属。
- 每层允许顶/底声速线性变化；当前 fixture 使用三层常声速。
- 射线使用 Snell 参数、自适应 Simpson 积分和深度二分求解，默认时间容差 `1e-10 s`、积分容差 `1e-12`。
- 校正波束角为“原始发射角 + roll”；姿态查询时间为“Ping 时间 + 姿态版本时延”。
- 剖面只在自身有效闭区间内可用，不跨空档插值。
- 超过剖面最大深度时返回 `BELOW_PROFILE_MAX_DEPTH`，不产生深度，不回退平均声速。
- 全反射或层内回转返回 `RAY_BLOCKED`；迭代失败返回 `NUMERIC_NO_CONVERGENCE`。
- 成功和失败点都保留输入波束/Ping 身份、经过分层、射线顶点、数值容差、姿态版本和姿态样本 ID。
- 校正角绝对值超过阈值时返回 `EXCLUDED_BEAM_ANGLE`，不执行射线求解。

## 固定 Fixture

- `P1`：`08:00Z-09:00Z`，0-10 m、10-25 m、25-40 m，含端点恰好在 25 m 的波束。
- `P2`：`10:00Z-11:00Z`，0-8 m、8-20 m、20-30 m，`P2-A-B05` 要求 34 m，超过最大深度 30 m。
- `GAP-1-B01`：`09:30Z`，处于两个剖面之间的一小时空档。
- `V0` 与 `V250`：0 ms 与 +250 ms 姿态时延，各自保留独立姿态样本身份。
- 不同 Ping 的有效海底点东向距离不超过 25 m 时形成相邻条带交叉差。

## 安装与演示

安装：

```bash
mvn -q -DskipTests package
```

测试并启动：

```bash
mvn -q test && mvn -q spring-boot:run -Dspring-boot.run.arguments=--server.port=5567
```

访问：

```text
http://127.0.0.1:5567
```

页面应显示“声速测深裁决台”。

## 页面与接口

- 页面可选择 `P1`/`P2` 有效时段、`V0`/`V250` 姿态版本和最大校正波束角。
- SVG 展示剖面分层、波束射线、海底点带、失败射线和交叉差。
- `GET /api/state`：读取剖面、姿态版本和最近运行。
- `POST /api/runs`：执行裁决。
- `GET /api/runs/{id}`：读取一次运行。
- `GET /api/runs/{id}/export.csv`：导出运行记录。
- `POST /api/replay`：清空业务数据并重新导入固定 fixture。

## 清空后复核

默认数据库为 `data/sounding-bench.sqlite`。关闭服务后删除该文件，重新启动会自动导入 fixture；也可在页面点击“清空并重新导入 fixture”或调用：

```bash
curl -X POST http://127.0.0.1:5567/api/replay
```

重新导入后使用相同参数重放，样本计数、状态、深度和交叉差应一致。

## 自动化测试

`mvn -q test` 覆盖严格递增校验、分层面唯一归属、两种姿态延迟、角度排除、空档不插值、越深不回退平均声速、全反射、清空重导入和页面标题。
